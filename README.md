# Stetwise by Ouroboros

Safe, reversible edits to Excel (`.xlsx`, `.xlsm`) and Word (`.docx`) for ChatGPT, Claude, Cursor, and Grok.

Every write is a preview first. Apply stores a new version only after the engine checks that untouched package parts kept their compressed bytes. Undo publishes an earlier version as a new head. If an edit cannot be done without risking formulas, styles, charts, pivot tables, shapes, comments, or tracked changes, Stetwise refuses it.

This repository does not deploy the service and does not create cloud accounts. `https://stetwise.app/mcp` in `server.json` is the planned address. It is not live. `stetwise.com` is a parked name and is not this product. Support: [ouroborosplugins@gmail.com](mailto:ouroborosplugins@gmail.com).

## Run locally

```bash
python3 -m pip install --user -r engine/requirements.txt
npm install
npm run build
STETWISE_DEV_AUTH=1 STETWISE_SIGNING_SECRET=change-me npm start
```

The dev bearer is `STETWISE_DEV_TOKEN` (default `dev-stetwise`). Dev auth is ignored when `NODE_ENV=production`. Leave `ENGINE_URL` unset to run the Python engine as `python3 -m stetwise` beside the server. Set `ENGINE_URL` and `ENGINE_HMAC_SECRET` to call the container instead.

```bash
docker build -f engine/Dockerfile -t stetwise-engine engine
docker run --rm -p 8080:8080 -e ENGINE_HMAC_SECRET=change-me stetwise-engine
```

The root `Dockerfile` is the Node MCP image (the Glama check). It does not contain the Python engine. For a long-running HTTP process set `STETWISE_HTTP_ONLY=1` so a closed stdin does not also start the stdio transport.

```bash
curl -T ./model.xlsx "$UPLOAD_URL"
```

`start_upload` returns that URL. It is one-time and lasts 15 minutes. `export` returns a download link that lasts 15 minutes.

| `STRIPE_SECRET_KEY` | Stripe secret key. |
| `STRIPE_WEBHOOK_SECRET` | Signing secret for `POST /billing/webhook`. |
| `STRIPE_PRODUCT_ID` | Existing product `prod_VQ12q90uKDcoto` (Stetwise by Ouroboros). |
| `STRIPE_PRICE_MONTHLY` | Existing monthly price `price_1UPB0453QnCs3zydekVagtYa`. This is the default Checkout price. |
| `STRIPE_PRICE_YEARLY` | Existing yearly price `price_1UPB0953QnCs3zydvFaCDgDw`. Used when the yearly plan is selected. |
| `APP_BASE_URL` | Public origin. MCP resource is `{APP_BASE_URL}/mcp`. |
| `ENGINE_URL`, `ENGINE_HMAC_SECRET` | Engine container. Unset `ENGINE_URL` uses the local Python module. |
| `STETWISE_DATA_DIR` | Local database directory. Default `.data`. |
| `STETWISE_SIGNING_SECRET` | HMAC for upload and download links. |
| `STETWISE_PURGE_SECRET` | `POST /internal/purge` header `x-stetwise-purge`. |
| `STETWISE_DEV_AUTH`, `STETWISE_DEV_TOKEN` | Local bearer. Refused in production. |
| `STETWISE_PYTHON` | Python executable. Default `python3`. |
| `STETWISE_HTTP_ONLY` | Set to `1` on the HTTP host. |
| `OPENAI_APPS_CHALLENGE` | Optional ChatGPT domain check. |
| `PORT` | HTTP port. Default `3000`. |

Checkout sends `line_items[0][price]` set to `STRIPE_PRICE_MONTHLY` or `STRIPE_PRICE_YEARLY`. It sets `subscription_data[trial_period_days]` to 14. It does not create a product or a price, and it does not send an amount. Stripe shows the amount. While `subscription_status` is `trialing`, the server enforces the trial caps below (100 applied edits and 20 recalculations), even if the Stripe plan name is already Pro. An `active` subscription uses the Pro caps. Past a cap the call is blocked. There is no overage charge.

Monthly caps, overridable without a code change:

| Variable | Default |
|---|---|
| `STETWISE_CAP_PRO_EDITS` | 1000 |
| `STETWISE_CAP_PRO_FILES` | 250 |
| `STETWISE_CAP_PRO_RECALCS` | 200 |
| `STETWISE_CAP_PRO_MAX_BYTES` | 26214400 (25 × 1024 × 1024) |
| `STETWISE_CAP_TRIAL_EDITS` | 100 |
| `STETWISE_CAP_TRIAL_FILES` | 25 |
| `STETWISE_CAP_TRIAL_RECALCS` | 20 |
| `STETWISE_CAP_TRIAL_MAX_BYTES` | 26214400 |

Trial file cap defaults to 25 new files per UTC month. Pro is 250. A trialing subscription uses the trial caps. An active subscription uses the Pro caps, including a yearly plan. Counters are per user and per UTC month. Deleting a file does not refund that month's file count. Restore does not count as an applied edit. A refused recalculation does not count.

Files expire 24 hours after last use. `set_retention` accepts 24 or 168 (7 days). `POST /internal/purge` deletes expired bytes.

## What works in v1

- Inspect, read a range or section, and search `.xlsx`, `.xlsm`, and `.docx`.
- `propose_edit` then `apply_edit` for `set_cells`, `insert_rows`, `insert_cols`, `replace_text`, `replace_paragraph`, and `update_table_cells`.
- Versions, undo, and a signed download link.
- ChatGPT file import (`import_file`) and a signed upload link for other clients.
- OAuth metadata, consent, Stripe checkout with a 14-day trial, and the billing portal. Same account shape as Continuity.
- Byte-level refusal when a workbook or document cannot be edited safely. Untouched zip entries are copied with their original compressed bytes.

## Refused by design

- PowerPoint, Google Drive, OneDrive, and edits of several files in one call.
- Legacy `.xls`, `.doc`, and `.ppt`, and encrypted or IRM files.
- Running macros. `vbaProject.bin` is copied and never executed.
- Creating or rewriting pivot tables, chart XML, slicers, or Excel tables.
- Shared formulas, protected sheets, and the non-origin cell of a merge.
- Inserting rows or columns when the workbook has pivots, charts, drawings, tables, shared formulas, 3D references, macros, comments, or protection.
- Word edits while track changes are on, or while the document is protected. v1 does not write new `w:ins` or `w:del` and does not turn tracking off.
- Rewriting comments, headers, footers, footnotes, or endnotes.
- LibreOffice recalculation and PDF or PNG previews. `recalculate` exists so the monthly cap is enforced, then refuses.
- Private, loopback, and link-local download URLs.

## Known gaps

- The running server stores accounts, files, versions, proposals, and monthly usage in `STETWISE_DATA_DIR` (JSON plus content-addressed blobs). `supabase/schema.sql` is the Postgres shape, including `usage_monthly`. It is not applied to a live project here.
- No Excel-saved golden file for row insert. The shifter follows Excel's reference rules and is tested on the hand-built model.
- Formula edits clear the cached value and set `fullCalcOnLoad`. Chart caches and pivot caches are not refreshed.
- Replacing several matches in one Word paragraph is not reliable when the replacement length changes. One match is the supported case.
- Vercel request bodies are about 4.5 MB. A 25 MB upload needs the Node process (`Dockerfile`) or a later direct-to-storage upload. The engine image stays out of the Vercel bundle.
- The engine port must not be public. Require `ENGINE_HMAC_SECRET` and a network policy.
- DNS rebinding between the address check and the connection is still possible. Hosts that resolve to private addresses are refused at check time.
- `openpyxl` is not used. Whole-workbook saves drop shapes and pivots, so edits stay at the package and XML part.
